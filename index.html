Als Android App (Capacitor)

1. Projekt-Setup: npm init -y
npm install @capacitor/core @capacitor/cli @capacitor/android
2. Ordnerstruktur:

Erstelle den Ordner www/ und speichere diese Datei als www/index.html.

3. APK bauen: npx cap init "Trumpet Master" "com.trumpet.master"
npx cap add android
npx cap copy
npx cap open android
4. Mikrofon-Berechtigung:

Füge in android/app/src/main/AndroidManifest.xml folgendes hinzu:

<uses-permission android:name="android.permission.RECORD_AUDIO" />
